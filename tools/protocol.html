Aurora patch sync

The bench instrument for shared/aurora_protocol.h § "System Exclusive". It pushes a library of known bytes, reads it back and compares, so the protocol can be told apart from the editor when something misbehaves. Chrome only, and it asks for SysEx permission. Backup and restore

The recovery path when the editor's machine is gone. What comes back is everything the brain was given — names, times, keypad assignment, every part — and nothing it was never given, so anything the editor knows and does not sync is not in here.
